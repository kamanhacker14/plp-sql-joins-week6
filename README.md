# Week 6 Assignment: SQL Joins and Relationships

This project contains SQL queries that combine data from related tables in the MySQL Classic Models database using INNER JOIN, LEFT JOIN, and RIGHT JOIN.

## Files
- `answer.sql` - contains the queries for Questions 1, 2, and 3

## Queries
1. **INNER JOIN** - employees and offices (firstName, lastName, email, officeCode)
2. **LEFT JOIN** - products and productlines (productName, productVendor, productLine)
3. **RIGHT JOIN** - customers and orders, first 10 orders (orderDate, shippedDate, status, customerNumber)

## How to run
1. Load the `classicmodels` database in MySQL Workbench.
2. Open `answer.sql`.
3. Run each query and check the results.
